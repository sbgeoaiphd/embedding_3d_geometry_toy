Put your files here:

- embeddings.json
  An array of objects:
    { "id": "…", "class": "label", "embedding": [64 floats] }

- class_ws.json
  An object mapping class label -> [64 floats]
  Example:
    { "forest": [..64..], "water": [..64..], ... }

You can keep the example files around as a schema reference.
